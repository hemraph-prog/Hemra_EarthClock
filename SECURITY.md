# Security Policy

## Supported Versions

EarthClock is currently a small browser-based project and does not maintain multiple released versions.

| Version         | Supported          |
| --------------- | ------------------ |
| Current version | :white_check_mark: |
| Older versions  | :x:                |

Security fixes, when necessary, will be applied to the current version of EarthClock.

## Reporting a Vulnerability

If you discover a security vulnerability in EarthClock, please report it privately through GitHub rather than creating a public issue.

When reporting a vulnerability, please include:

* A clear description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any relevant screenshots, code, or console errors

Please do not publicly disclose the vulnerability before it has been reviewed.

The project maintainer will review the report and respond as soon as reasonably possible.

If the vulnerability is confirmed, appropriate changes will be made and the affected code will be updated.
If the report is not considered a security vulnerability, an explanation will be provided where appropriate.

Thank you for helping keep EarthClock secure.

# Contributing to EarthClock

Thank you for your interest in contributing to EarthClock.

EarthClock is a browser-based astronomical visualization built with JavaScript, Three.js, WebGL, HTML, and CSS.

## How to Contribute

You can contribute by:

* Reporting bugs
* Suggesting new features
* Improving the documentation
* Improving the user interface
* Improving the astronomical calculations
* Improving performance
* Submitting code changes

## Reporting Bugs

Before reporting a bug, please check whether the issue has already been reported.

When creating a bug report, include:

* A clear description of the problem
* Steps to reproduce it
* Expected behavior
* Actual behavior
* Browser and operating system
* Console errors, if available
* Screenshots or recordings when useful

## Suggesting Features

Feature suggestions are welcome.

Please explain:

* What the feature should do
* Why it would be useful
* How it could improve EarthClock

## Code Contributions

When submitting code:

* Keep the code readable and understandable.
* Use clear names for variables and functions.
* Keep changes focused on the purpose of the contribution.
* Avoid unnecessary dependencies.
* Do not include passwords, API keys, or other private information.
* Do not make unrelated changes to the project.

## Three.js

EarthClock currently uses Three.js `0.180.0`.

If you change the Three.js version, make sure the project still works correctly and explain the reason for the change.

## External Resources

EarthClock uses external resources, including Three.js and astronomical textures.

Third-party resources may have their own licenses. Do not assume that the EarthClock MIT License automatically applies to external resources.

## Testing

Before submitting a pull request, test the project in a modern browser.

Please check that:

* The Earth renders correctly.
* The Moon renders correctly.
* The Sun lighting works correctly.
* The clock displays correctly.
* The date displays correctly.
* The `H` key still toggles the clock interface.
* No unexpected errors appear in the browser console.
* WebGL rendering works correctly.

## Pull Requests

Pull requests should:

* Have a clear title.
* Explain what was changed.
* Explain why the change was made.
* Include testing information.
* Include screenshots or recordings when the visual appearance has changed.

Please keep pull requests focused on one main change.

## Questions

If you are unsure about a proposed change, open an issue before making a large change.

Thank you for helping improve EarthClock.
